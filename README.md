## 🎯 نبذة عن المنظومة (Product Overview)

**مُرافِق (Murafiq)** هي منظومة مؤسسية متكاملة ومتعددة المستأجرين (Multi-Tenant Enterprise Platform) تُباع للمؤسسات والجهات الحكومية والتعليمية والصحية والتجارية لإدارة الحالات، والشكاوى، وطلبات الخدمة، والنزاعات، وبناء خطط العمل، وتتبع مراحل الإنجاز حتى التسوية النهائية وقياس رضا المستفيدين.

> **شعار المنظومة وقيمتها الجوهرية (Core Promise):**
> *«لكل قضية مسؤول، ولكل إجراء موعد نهائي، ولكل التزام تتبع، ولكل حل أثر قابل للقياس.»*
> *"Every issue gets an owner, every action gets a deadline, every commitment gets tracked, and every resolution becomes measurable."*

---

## 🚫 توضيح جوهري (What Murafiq Is NOT)

* **ليست منصة تقييمات عامة (Not a Public Review Directory):** مُرافِق لا تنشر آراء استهلاكية أو تقييمات تشهيرية للعموم.
* **ليست دليلاً مفتوحاً للتشهير:** البيانات تُعالج داخل سياق مؤسسي محكم ومحمي بالقانون.
* **منظومة عمل مؤسسية خاصة (B2B SaaS / Enterprise On-Premise):** كل مؤسسة تحصل على بوابتها المستقلة بهويتها البصرية، وأقسامها الإدارية، وسياسات مستوى الخدمة (SLA) الخاصة بها.

## 🔄 مسار المعالجة المؤسسية الموحد (Core Resolution Loop)

```
المستفيد (طالب/ولي أمر/مريض/مواطن/عميل)
    │
    ▼
تقديم الحالة وتوليد الرقم المرجعي الآمن
    │
    ▼
الفرز الآلي وتحديد الأولوية والقسم المختص (Triage & Department Routing)
    │
    ▼
تعيين مسؤول الحالة وربط مهلة الإنجاز (Assignment & SLA Target)
    │
    ▼
التواصل الثنائي والملاحظات الداخلية المحمية (Internal Notes & Beneficiary Thread)
    │
    ▼
بناء خطة العمل ثلاثية المراحل (Action Plan & Milestone Milestones)
    │
    ▼
التنفيذ الميداني وتوثيق الأدلة والإغلاق (Execution & Resolution)
    │
    ▼
تقييم المستفيد وقياس جودة التسوية (Beneficiary Evaluation & RQS)
    │
    ▼
تقرير التسوية الموثق رقمياً ولوحات القيادة التنفيذية (Executive Analytics & Audit PDF)
```

## 👥 البوابات والأدوار المؤسسية (Portals & Access Roles)

1. **بوابة المستفيدين (Beneficiary Portal & Tracking):**
   * تقديم الحالات والشكاوى والطلبات بخطوات استرشادية واضحة.
   * تتبع مسار الحالة برقم التتبع المشفر دون الحاجة لإنشاء حساب معقد.
   * الاطلاع على مراحل خطة العمل المعتمدة والتواصل مع مسؤول الحالة.
   * تقييم جودة التسوية فور اكتمالها وتحميل تقرير الإغلاق الموثق.

2. **بوابة موظفي المعالجة والفرز (Staff Triage & Operations Portal):**
   * استعراض الحالات الواردة ومصفوفة الأولويات والأقسام.
   * تسجيل الملاحظات الداخلية المحمية (`Internal Notes`) المحجوبة عن المستفيد.
   * بناء خطط العمل المرحلية وتعيين المسؤولين وتحديث حالات الإنجاز.
   * متابعة مؤقتات الـ SLA ومعدلات الانضباط الزمني.

3. **لوحة تحكم مدير المؤسسة (Organization Admin Portal):**
   * إدارة الهوية البصرية (الشعار، الألوان، النطاق المخصص).
   * هيكلة الأقسام الإدارية ومسؤولي الفرز.
   * ضبط سياسات مستوى الخدمة (SLA) وساعات العمل الرسمية.
   * إدارة حسابات الموظفين والصلاحيات (Admin, Ops Lead, Staff, Observer).

4. **لوحة القيادة والتحليلات التنفيذية (Executive Analytics Dashboard):**
   * مؤشرات الالتزام باتفاقيات مستوى الخدمة (% SLA Compliance).
   * بطاقة أداء الأقسام الداخلية (Department Performance Scorecards).
   * توزيع الحالات حسب الأولوية ومصادر الاختناق التشغيلي.
   * مؤشر جودة التسوية المؤسسية (Resolution Quality Score - RQS).

## 🤖 محركات الذكاء الاصطناعي المؤسسي المزدوج (Dual AI Engines)

1. **المساعد الفوري للمستفيدين (Concierge AI):**
   * إرشاد المستفيد في صياغة مطلبه وتحديد القسم المناسب وتوضيح مسار العمل.
   * مدعوم بنموذج `NVIDIA NIM — nemotron-3.5-lightning-30b`.
2. **مستشار الحلول وخطط المعالجة (Solution & Action Plan Advisor):**
   * اقتراح خطط عمل مؤسسية ثلاثية المراحل للموظفين مع مراعاة اللوائح والتشريعات المصرية المعمول بها.
   * مدعوم بنموذج `NVIDIA NIM — meta/muse-glimmer-30b`.

## 🛡️ الأمان والامتثال والعزل التام (Security & Multi-Tenant Isolation)

* **عزل المستأجرين (Tenant Isolation):** عزل تام لبيانات كل مؤسسة عبر معرف المستأجر (`tenant_id / institution_id`) وسياسات مستوى الصف (RLS).
* **حماية البيانات الشخصية (Egyptian Law 151/2020 Compliance):**
  * فصل مادي تام لبيانات الهوية والرقم القومي في جدول مشفر مستقل (`case_sensitive_data`).
  * تشفير قنوات الاتصال وتشفير البيانات أثناء التخزين والنقل.
* **البصمة الرقمية الموثقة (Cryptographic Digest):**
  * توليد تقارير التسوية والإغلاق بصيغة PDF ممهورة ببصمة `SHA-256` لحمايتها من التزوير.
* **قنوات الإشعار الفورية:** تكامل رسمي مع Meta Cloud API (WhatsApp) لإرسال تحديثات الحالة اللحظية.

## 🚀 البدء السريع والتشغيل المحلي (Getting Started)

### 1. المتطلبات الأساسية
* Node.js ≥ 18.18.0
* npm أو yarn أو pnpm

### 2. التثبيت والتشغيل
```bash
# استنساخ المشروع
git clone https://github.com/am21951691-cloud/Murafiq.git
cd Murafiq

# تثبيت الاعتماديات
npm install

# ضبط متغيرات البيئة
cp .env.example .env.local

# تشغيل خادم التطوير
npm run dev
```
افتح المتصفح على: `http://localhost:3000`

### 3. تشغيل حزمة الاختبارات
```bash
npm test
```
* يشمل 26 ملف اختبار يغطي العزل متعدد المستأجرين، دورة حياة الحالات، الـ SLA، وأمان البيانات.

### 4. بناء نسخة الإنتاج
```bash
npm run build
npm start
```
